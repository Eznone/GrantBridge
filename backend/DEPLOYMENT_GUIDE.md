# GrantBridge Deployment Guide

Complete guide for deploying GrantBridge backend to production.

## 📋 Prerequisites

- [ ] Supabase account (or PostgreSQL database)
- [ ] Render.com account (or alternative hosting)
- [ ] IBM watsonx.ai account
- [ ] Domain name (optional)
- [ ] Email SMTP credentials (optional)

## 🗄️ Database Setup (Supabase)

### 1. Create Supabase Project

1. Go to [supabase.com](https://supabase.com)
2. Click "New Project"
3. Fill in project details:
   - **Name**: grantbridge-prod
   - **Database Password**: (generate strong password)
   - **Region**: Choose closest to your users
4. Wait for project creation (~2 minutes)

### 2. Get Connection String

1. Go to **Project Settings** → **Database**
2. Find **Connection String** section
3. Copy the **URI** format:
   ```
   postgresql://postgres:[YOUR-PASSWORD]@db.[PROJECT-REF].supabase.co:5432/postgres
   ```
4. Save this for later (DATABASE_URL)

### 3. Configure Database

```sql
-- Optional: Create read-only user for analytics
CREATE USER analytics_user WITH PASSWORD 'secure_password';
GRANT CONNECT ON DATABASE postgres TO analytics_user;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO analytics_user;
```

## 🚀 Render.com Deployment

### Option A: Using Blueprint (Recommended)

1. **Connect Repository**
   - Go to [render.com](https://render.com)
   - Click "New" → "Blueprint"
   - Connect your GitHub repository
   - Select the repository containing `render.yaml`

2. **Configure Environment Variables**

   Render will detect `render.yaml` and prompt for these variables:

   ```bash
   # Required
   DJANGO_ALLOWED_HOSTS=your-app.onrender.com
   DATABASE_URL=<your-supabase-connection-string>
   CORS_ALLOWED_ORIGINS=https://your-frontend.vercel.app

   # AI Services
   WATSONX_API_KEY=<your-watsonx-api-key>
   WATSONX_PROJECT_ID=<your-watsonx-project-id>

   # Optional
   EMAIL_HOST=smtp.gmail.com
   EMAIL_HOST_USER=your-email@gmail.com
   EMAIL_HOST_PASSWORD=<app-password>
   SENTRY_DSN=<your-sentry-dsn>
   ```

3. **Deploy**
   - Click "Apply"
   - Render will build and deploy automatically
   - First deployment takes ~5-10 minutes

### Option B: Manual Setup

1. **Create Web Service**
   - Go to Render Dashboard
   - Click "New" → "Web Service"
   - Connect repository

2. **Configure Build Settings**

   ```
   Name: grantbridge-api
   Environment: Python 3
   Region: Oregon (or closest)
   Branch: main
   Build Command: pip install -r requirements.txt && python manage.py collectstatic --no-input && python manage.py migrate
   Start Command: gunicorn config.wsgi:application
   ```

3. **Set Environment Variables**
   (Same as Option A above)

4. **Create PostgreSQL Database** (if not using Supabase)
   - Click "New" → "PostgreSQL"
   - Name: grantbridge-db
   - Plan: Starter ($7/month)
   - Copy connection string to DATABASE_URL

## 🔐 Environment Variables Reference

### Required Variables

| Variable                 | Description            | Example                          |
| ------------------------ | ---------------------- | -------------------------------- |
| `DJANGO_SETTINGS_MODULE` | Settings module        | `config.settings.production`     |
| `DJANGO_SECRET_KEY`      | Django secret key      | Auto-generated by Render         |
| `DJANGO_ALLOWED_HOSTS`   | Allowed hostnames      | `api.grantbridge.com`            |
| `DATABASE_URL`           | PostgreSQL connection  | `postgresql://user:pass@host/db` |
| `CORS_ALLOWED_ORIGINS`   | Frontend URLs          | `https://app.grantbridge.com`    |
| `WATSONX_API_KEY`        | IBM watsonx.ai API key | `your-api-key`                   |
| `WATSONX_PROJECT_ID`     | IBM watsonx.ai project | `your-project-id`                |

### Optional Variables

| Variable                     | Description           | Default          |
| ---------------------------- | --------------------- | ---------------- |
| `JWT_ACCESS_TOKEN_LIFETIME`  | Access token minutes  | `15`             |
| `JWT_REFRESH_TOKEN_LIFETIME` | Refresh token minutes | `10080` (7 days) |
| `EMAIL_HOST`                 | SMTP server           | `smtp.gmail.com` |
| `EMAIL_PORT`                 | SMTP port             | `587`            |
| `EMAIL_HOST_USER`            | SMTP username         | -                |
| `EMAIL_HOST_PASSWORD`        | SMTP password         | -                |
| `SENTRY_DSN`                 | Error tracking        | -                |

## 🌐 Custom Domain Setup

### 1. Add Custom Domain in Render

1. Go to your service settings
2. Click "Custom Domains"
3. Add your domain: `api.grantbridge.com`
4. Render provides DNS records

### 2. Configure DNS

Add these records to your DNS provider:

```
Type: CNAME
Name: api
Value: your-app.onrender.com
```

### 3. Update Environment Variables

```bash
DJANGO_ALLOWED_HOSTS=api.grantbridge.com,your-app.onrender.com
CORS_ALLOWED_ORIGINS=https://grantbridge.com,https://www.grantbridge.com
```

## 🐛 Troubleshooting

### Build Failures

**Issue**: `ModuleNotFoundError`

```bash
# Solution: Check requirements.txt
pip freeze > requirements.txt
```

**Issue**: Static files not found

```bash
# Solution: Ensure collectstatic runs
python manage.py collectstatic --no-input
```

### Database Connection Issues

**Issue**: `could not connect to server`

```bash
# Solution: Check DATABASE_URL format
# Must include ?sslmode=require for Supabase
postgresql://user:pass@host:5432/db?sslmode=require
```

### CORS Errors

**Issue**: Frontend can't connect

```bash
# Solution: Update CORS_ALLOWED_ORIGINS
# Include both production and preview URLs
CORS_ALLOWED_ORIGINS=https://app.vercel.app,https://app-preview.vercel.app
```

### Memory Issues

**Issue**: Service crashes with OOM

```bash
# Solution: Upgrade Render plan
# Or optimize queries with select_related/prefetch_related
```
